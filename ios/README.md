# The Western Rite prayers, as an iOS app

A native wrapper around the Western Rite half of the app: the Little Prayer
Book, Compline, the St. Peter Pew Missal and the fasting norms. Everything is
bundled in the binary — **the app makes no network requests at all** — so it
works in a basement, on a plane, and in church.

This is built for sideloading onto your own device. Nothing here assumes the
App Store.

## What it is

Capacitor puts the generated site inside a `WKWebView`. `build.py` stays the
single source of truth for the content; the app is just a second output target.

| | Web build | iOS build |
|---|---|---|
| Command | `python3 build.py` | `npm run build` |
| Output | the repo root (Vercel deploys it) | `ios/www/` |
| Content | Western Rite | Western Rite |
| Size | ~1.5 MB | ~1.5 MB |
| Favicon, manifest, service worker | yes | no — a WebView needs none |
| Assets | already in place | copied into `ios/www/` |

Both builds carry the same 17 pages now: the site itself is a Western Rite
prayer book. The only difference is the target.

Two switches, deliberately separate:

- `WESTERN_ONLY` — content scope, on by default. **`WESTERN_ONLY=0` brings the
  whole Eastern side back**: the Bible reader, the calendar, the Greek tool,
  the resources, the rite gate. Nothing was deleted from `build.py`; those
  pages simply stop being written. The Eastern runtime files are still in the
  repo, just out of the deploy (see `.vercelignore`).
- `APP_BUILD` — the bundled-app target, which is what `npm run build` sets.

## What you need on the Mac

- **Xcode**, with the command line tools.
- **Node 20+** and **python3** (the iOS build only uses the standard library —
  Pillow is *not* needed unless you re-cut the icons).
- Your Apple Developer account signed in to Xcode.

## First run

```sh
npm install
npx cap add ios          # creates ios/App — only needed once
npm run icons            # copies the app icons into the Xcode catalog
npm run open             # builds the web content, syncs it, opens Xcode
```

`npm run icons` needs Pillow (`pip3 install pillow`). If you skip it, copy
`ios/AppIcon.appiconset/` over `ios/App/App/Assets.xcassets/AppIcon.appiconset/`
by hand — the generated files are committed, so they're already there.

In Xcode: select the **App** target → **Signing & Capabilities** → pick your
team. Change the bundle identifier in `capacitor.config.json` if
`com.othroprayers.western` collides with something you already have. Then pick
your iPhone from the device menu and hit Run.

## After changing content

```sh
npm run open      # rebuild, sync, open Xcode
```

or, without opening Xcode:

```sh
npm run sync
```

## The app icon

iOS 18 takes three appearances, and all three are in
`ios/AppIcon.appiconset/`:

- `AppIcon-1024.png` — the bronze medallion (light)
- `AppIcon-1024-dark.png` — the steel one (dark)
- `AppIcon-1024-tinted.png` — greyscale, which the system recolours

This is the thing the web version cannot do: on the home screen the icon now
follows the phone's appearance. They're generated by `generate_icons.py --ios`
from the two masters in `assets/icons/`.

**Known limitation:** the masters are only 356px, cut out of a screenshot, so
the 1024px icons are a ~2.9× upscale and are softer than they should be.
Unsharp masking claws some of it back, but the real fix is the original
artwork at full size — drop it in and re-run `npm run icons`.

## Sideloading notes

- A **free** Apple ID signs apps that expire after 7 days. A paid Developer
  Program membership ($99/yr) gets a year.
- Installing to a device needs the phone plugged in (or on the same network
  with wireless debugging enabled) and the device trusted in Xcode.
- First launch on the phone: **Settings → General → VPN & Device Management**,
  then trust your developer certificate.

## What isn't here, and what it would take

Ported from the web build but not yet native:

- **Prayer-time reminders.** The obvious win — local notifications need no
  server, unlike web push. `@capacitor/local-notifications` plus a schedule
  from the hours of the office.
- **A home screen widget.** Today's office, or the day's fast. This is real
  Swift work, not a Capacitor plugin.
- **A launch screen.** Capacitor's default is a blank white view, which will
  flash before the first paint — jarring in dark mode. Worth setting to the
  paper colour (`#faf6ee` light, `#161518` dark) in the Xcode storyboard.
